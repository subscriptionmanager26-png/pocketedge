# Portfolio share templates

Static HTML references for portfolio snapshot cards. Production in-app rendering lives in `src/components/PortfolioShareCard.jsx`.

| Template | File | Canvas | Use case |
|----------|------|--------|----------|
| **Bubble snapshot** | `templates/bubble-snapshot.html` | 800px card | Top 5 performers by return (bubble viz) + top 10 holdings |
| **List snapshot** | `templates/list-snapshot.html` | 375×667 | Mobile share card — top 5 performers + top 5 by weight |

Open templates in a browser from this directory so relative asset paths resolve.
